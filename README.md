# 🎮 Rock Paper Scissors Game

A fun, interactive **Rock Paper Scissors game built using Python**. Play against the computer, test your luck, and track scores throughout the game!

## 📌 About the Project

This project is a beginner-friendly Python game that lets users play Rock Paper Scissors against a computer opponent. The computer randomly selects Rock, Paper, or Scissors, and the program determines the winner based on the game rules.

The game continues until the player chooses to stop, displaying the final scores at the end.

## ✨ Features

- 🎯 **Interactive Gameplay:** Choose Rock, Paper, or Scissors using numbered options.
- 🤖 **Random Computer Moves:** The computer selects its move randomly.
- 🏆 **Winner Detection:** Automatically determines the winner of each round.
- 🔢 **Score Tracking:** Tracks the player's and computer's scores.
- 🔁 **Replay Option:** Continue playing multiple rounds without restarting.
- 🛡️ **Input Validation:** Handles non-numeric inputs and prompts users to enter valid choices.
- 🤝 **Tie Detection:** Identifies when both choices are the same.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Module:** `random`
- **Concepts:** Loops, conditional statements, lists, exception handling, user input, and random number generation.

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/geethakrishnapedapudi/Stone-paper-Scissors.git
   ```

3. Navigate to the project folder:

   ```bash
   cd Stone-paper-Scissors
   ```

4. Run the Python file:

   ```bash
   python spr.py
   ```

## 🎮 How to Play

1. Run the program.
2. Enter `1` for Rock, `2` for Paper, or `3` for Scissors.
3. The computer will randomly choose its move.
4. The game announces the round result and updates the scores.
5. Enter `y` to play another round or `n` to exit.
6. View the final scores when the game ends.

## 📜 Game Rules

- 🪨 Rock beats Scissors.
- 📄 Paper beats Rock.
- ✂️ Scissors beats Paper.
- 🤝 Identical choices result in a tie.
